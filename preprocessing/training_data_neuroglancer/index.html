Plasmodesmata - Training Data

Per-dataset Neuroglancer links and source pointers for the leaf-gall plasmodesmata training data. All sources point at OME-NGFF multiscale parent groups, so Neuroglancer reads the axis labels (z/y/x) and per-scale transforms automatically and picks the appropriate level for the current view.

  • raw — EM volume: recon-1/em/fibsem-uint8 multiscale group. 8 nm datasets are native at s0; the 4 nm b volumes are native 4 nm at s0 with s1 at 8 nm.
  • gt_cylinders — rasterized cylindrical ground-truth: each annotation line drawn as a cylinder. This is what the model was trained against. Source: annotations_as_cylinders.zarr/<dataset>.
  • annotation_intersection_mask — loss mask restricting the training loss to the annotated regions. Source: annotation_intersection_masks.zarr/<dataset>.
  • plasmodesmata_cleaned — post-MWS / postprocessed plasmodesmata instance segmentation (8 nm datasets only).
  • cell_fixed — proofread cell-mask segmentation used for downstream geodesic analysis (8 nm datasets only).
  • prediction_mask_dilation_N — dilated cell mask restricting model inference. N is the dilation-iterations setting used in whole_datasets/prediction_yamls/2025-09-15_<dataset>.yaml.
  • line_annotations — every annotation line as a single precomputed layer (where available).
  • kept_annotations / removed_annotations — same annotations pre-split into "yielded a training point" vs "didn't" (where the precomputed layers exist).
  • bounding_boxes — validation/test/training ROI boxes. Prefers the precomputed neuroglancer_annotations/<dataset>/bounding_boxes; falls back to an inline layer built from each dataset's training_validation_test_roi_info.yaml when no precomputed layer exists.
